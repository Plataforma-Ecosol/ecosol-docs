# Código de conduta

Este projeto nasce da Economia Solidária e segue os mesmos valores: cooperação,
respeito e autogestão.

- Trate todas as pessoas com respeito, sem discriminação de qualquer tipo.
- Critique ideias e trabalhos, nunca pessoas. Revisões de PR são para melhorar o
  trabalho de todos.
- Respeite a privacidade das pessoas e dos coletivos atendidos pela plataforma.
- Assédio, ofensas e exposição de dados de terceiros não são tolerados.

Problemas de conduta podem ser comunicados de forma reservada à coordenação do
projeto na ITES/IFRJ Campus Niterói. As pessoas que mantêm o repositório podem
remover conteúdos e restringir o acesso de quem descumprir estas regras.
